================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Cannot access account management"
SOLUTION: 
  1. Verify you're logged in as super admin
  2. Check sidebar subtitle shows "Portal Admin"
  3. Verify role in database: SELECT * FROM users WHERE email='admin@presensi.test';
  4. Clear cache: php artisan optimize:clear

PROBLEM: "Password validation errors"
SOLUTION:
  - Ensure password has: 8+ characters
  - Ensure password has: 1 uppercase letter
  - Ensure password has: 1 number
  - Ensure password has: 1 special character (!@#$%^&*, etc.)
  Example: MyPass123!

PROBLEM: "Pages not loading / styling looks broken"
SOLUTION:
  1. Clear cache: php artisan optimize:clear
  2. Clear browser cache: Ctrl+Shift+Delete (all time)
  3. Hard refresh: Ctrl+Shift+R

PROBLEM: "Super admin account not found"
SOLUTION:
  1. Run migrations: php artisan migrate
  2. Check migration status: php artisan migrate:status
  3. If needed, refresh DB: php artisan migrate:refresh
