# Deployment to Rumahweb - Quick Summary

Deploy Presence Teen to `presence.solvianova.my.id` in simple steps

## 🎯 Quick Overview

```
Local Project → Rumahweb Subdomain
D:\Project\presence-teen → https://presence.solvianova.my.id
```

## 📋 What You Need

✅ Rumahweb hosting account
✅ Domain: solvianova.my.id  
✅ FTP/SFTP client (FileZilla)
✅ SSH access (optional but recommended)
✅ Project tested locally
✅ 30-60 minutes time

## 🚀 The 10-Minute Version

### Step 1: Rumahweb Setup (10 min)

**1. Create Subdomain**
- cPanel → Subdomains → Create New Subdomain
- Subdomain: `presence`
- Domain: `solvianova.my.id`
- Document Root: `/public_html/presence.solvianova.my.id/` or `/public_html/presence/`

**2. Create Database**
- cPanel → MySQL Databases
- Database name: `solvianova_presence`
- User: `solvianova_presnc`
- Password: (strong password, save it!)
- Grant ALL PRIVILEGES

**3. Get FTP Credentials**
- cPanel → FTP Accounts
- Note: Host, User, Password

### Step 2: Prepare Project (5 min)

```bash
# Locally, in project directory
cd d:\Project\presence-teen

# Install dependencies
composer install --no-dev

# Build frontend
npm run build
```

### Step 3: Upload via FTP (20 min)

**Using FileZilla:**
1. Open FileZilla
2. File → Site Manager → New Site
3. Enter credentials from cPanel
4. Connect
5. Drag-drop project files (except .env, .git, node_modules, vendor)

### Step 4: Server Setup via SSH (15 min)

```bash
# SSH into server
ssh username@presence.solvianova.my.id

# Navigate to project
cd public_html/presence.solvianova.my.id

# Create .env
cp .env.example .env

# Edit .env - add your database credentials
nano .env
```

Edit these in `.env`:
```env
APP_URL=https://presence.solvianova.my.id
APP_ENV=production
APP_DEBUG=false

DB_DATABASE=solvianova_presence
DB_USERNAME=solvianova_presnc
DB_PASSWORD=your_database_password
```

```bash
# Generate app key
php artisan key:generate

# Install PHP dependencies
composer install --no-dev

# Run migrations
php artisan migrate --force

# Seed database (creates super admin)
php artisan db:seed --force

# Set permissions
chmod -R 755 public/
chmod -R 775 storage/
chmod -R 775 bootstrap/cache/

# Create storage link
php artisan storage:link

# Optimize
php artisan optimize
```

### Step 5: Verify (5 min)

✅ Visit: `https://presence.solvianova.my.id`
✅ Login: `admin@presensi.test` / `password`
✅ Check: Dashboard loads
✅ Verify: SSL certificate active

**Total Time: ~55 minutes**

## ❌ Common Issues & Quick Fixes

| Issue | Fix |
|-------|-----|
| 404 on routes | Check `.htaccess` in public/, enable mod_rewrite |
| "Database connection failed" | Verify credentials in .env |
| "No application encryption key" | Run: `php artisan key:generate` |
| Blank page / 500 error | Check: `tail -f storage/logs/laravel.log` |
| Can't upload files | Fix permissions: `chmod -R 775 storage/` |
| CSS/JS not loading | Run: `php artisan storage:link` |
