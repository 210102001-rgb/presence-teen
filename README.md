# presence-teen
PRESENCE-TEEN adalah ekosistem akademik pintar yang dirancang untuk membentuk kebiasaan tangguh pada pelajar. Menggabungkan keamanan presensi QR Code dinamis, pengingat tugas berbasis kalender terintegrasi, dan asisten peringkas materi, PRESENCE-TEEN menghubungkan siswa, guru, dan orang tua dalam satu platform yang transparan dan interaktif.
