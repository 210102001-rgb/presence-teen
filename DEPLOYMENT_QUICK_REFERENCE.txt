================================================================================
⚠️  COMMON PROBLEMS & FIXES
================================================================================

PROBLEM: 404 on /login and other routes
FIX: Check .htaccess in public/ folder
  - Verify mod_rewrite enabled on server
  - Ensure .htaccess file exists
  - Check: cat public/.htaccess

PROBLEM: "Database connection failed"
FIX: Verify credentials
  - Check .env has correct credentials
  - Verify database exists: mysql -u user -p database
  - Test connection: php artisan tinker → DB::connection()->getPdo()

PROBLEM: "No application encryption key"
FIX: Generate key
  - php artisan key:generate
  - Verify APP_KEY in .env

PROBLEM: Blank page or 500 error
FIX: Check logs
  - tail -f storage/logs/laravel.log
  - Look for [ERROR] or [Exception]
  - Fix reported issues

PROBLEM: Can't upload files
FIX: Fix permissions
  - chmod -R 775 storage/
  - Verify disk space available

PROBLEM: CSS/JS not loading
FIX: Create storage link
  - php artisan storage:link
  - Verify: ls -la public/ (should show storage link)

PROBLEM: Routes not working after migration
FIX: Clear route cache
  - php artisan route:clear
  - php artisan route:cache

================================================================================
📞 EMERGENCY PROCEDURES
================================================================================

IF PAGE IS BLANK / 500 ERROR:

1. SSH to server
2. Check logs:
   tail -50 storage/logs/laravel.log
3. Clear caches:
   php artisan optimize:clear
4. Rebuild caches:
   php artisan optimize
5. Check permissions:
   chmod -R 775 storage/
6. Verify .env:
   cat .env | head -10

IF DATABASE NOT WORKING:

1. Test connection:
   mysql -u solvianova_presnc -p
2. Verify credentials in .env:
   cat .env | grep DB_
3. Run migrations:
   php artisan migrate --force
4. Check if tables exist:
   mysql -u solvianova_presnc -p solvianova_presence
   > SHOW TABLES;

IF CAN'T LOGIN:

1. Verify super admin exists:
   mysql> SELECT * FROM users WHERE role='super_admin';
2. If missing, seed database:
   php artisan db:seed --force
3. Check user:
   mysql> SELECT id, email, role FROM users;
